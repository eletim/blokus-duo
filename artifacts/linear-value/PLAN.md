# 非NNの方策特徴・終局価値・探索の有限対照
基点6dd4a63、研究専用worktree。main/Web/service変更なし。
監査: 旧30係数はterminal WDL REINFORCE、learner側のみ勾配、batch開始自己50/past25/greedy初期25、各相手先後均等。9/10は行動非依存で除外済み。frontier増分と個数は同局面内で線形従属（絶対個数差は方策から相殺）；係数の個別解釈には注意。旧版の同ゲーム数対照を新規実行する。
新特徴は3つ: 現局面の同駒合法配置数（希少度）、自分が辺禁止でない空き連結成分の大きさを候補角で参照（着手後の厳密到達可能面積ではないproxy）、相手接続点の空き隣接度で重み付けした遮断。局面不変量は1回計算、配置幾何はcache。追加係数は0初期化、旧heuristic prior保持。NN方策/value/教師なし、gen3は評価相手だけ。
方策は両条件同じREINFORCE/NumPy Adam LR.03/16games/clip5/past64交換。旧30、新39係数。新しい訓練prefix系列をseed3101/2/3で共通化し、過去評価開始状態を除外。行動で以後軌跡が分岐する。
価値は新方式のlearner局面から最終WDLを線形最小二乗目的でAdam学習（別LR.01）。手番反転で符号が反転する局面差分特徴、3段階。方策損失には使わず価値学習の寄与を探索として分離。終局はルール得点から厳密WDL。
最初に各条件32iterationの速度pilot、以後の本学習は1024iteration=16384games/seed/条件を予定。予測30分を超えるなら結果を見る前に512へ固定。6run、生成更新保存90分上限。非有限/係数絶対値>1000で停止、無期限延長なし。中間256/512/1024を保存し選択せず終点固定。
学習後、独立64games/seedの価値校正: WDL MSEがゼロ予測より集約で改善する場合のみ先読みを実戦評価する。探索はroot6/応手3/depth2、6msと25msを新validation64prefixで比較。全root同深度完了時のみ値を使用、時間切れは元方策、両手番minimax。小終盤は独立全合法全探索と照合。枝制限探索を厳密とは呼ばない。
validation64prefix: 旧学習対旧初期、新学習対新初期、新対同経験旧、両者対公開gen3(対応seed1751401/2/3)。探索gateは単体へのpoint>=.5かつfallback<50%、価値校正gateも必要。6ms/25msのうち対単体point最大（同点6ms）を全seed共通固定。未達なら探索holdoutなし。
確認試験は未使用128prefixを固定（追加なし）。主比較は新対同経験旧、補助は新対初期とgen3。3比較pointのBonferroni98.333%CIと通常95%を併記。探索gate通過時のみ固定探索対単体/同予算の非学習葉探索/gen3を診断的追加（主要学習比較と混同しない）。prefix内3seed/両席クラスタCI。旧pilot成績は再利用しない。gen3は対応3seed、思考時間は同一ではない。
