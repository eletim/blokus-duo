# Future terminal occupancy: preregistered design, 2026-11-24

New research from main2529f505, separate branch research/gen4-future-occupancy. Preserve public gen4/Frozen/Web; no merge/deploy. Old PR2 experiments are not rerun.

## Questions and arms
A: direct value using common spatial/state features and existing252 mobility inputs.
B: same value, terminal occupancy auxiliary supervised loss on common features; predicted map never enters value.
C: same auxiliary loss, predicted 14x14x3 softmax explicitly enters value through a learned projection, retaining original features/state/mobility. No terminal truth is supplied to inference. All start from identical corresponding frozen-gen4 value weights per seed; new heads initialized with identical RNG, zero-initialized map-to-value projection. All arms have identical allocated modules; effective parameter use and inference cost reported separately. Candidate policies remain original fixed gen4, and search conditions identical.
Occupancy classes are current player/opponent/empty, from actual final board of fixed-gen4 search selfplay. Inputs are current board, remaining pieces/turn-state, and mobility only. Auxiliary CE and Brier focus on currently empty cells; known occupied probabilities clamped to current ownership at inference. No accuracy-only strength claim.

## Pilot and bounded finalization
Before main generation or inspecting main outcomes, run12 independent pilot games (4/teacher seed) with gen4-vs-gen4 CPU500ms,width4,max6 and diverse random8/10/12ply prefixes;4CPUworkers. Measure wall, memory, legal terminal labels, encoding and new model inference/training. Pilot excluded from main train/dev/test/evaluation. Test perspective swaps, symmetry transforms, occupied-cell invariance, pass/terminal/score, and value input isolation.
Provisional main budget:1536 train+192dev+192heldout label-test games, evenly across3 teacher seeds; all arms/3 initialization seeds share the same game split.8epochs Adam1e-4 batch128; value MSE(sign terminal score difference), B/C add0.25 empty-cell CE. Select each arm/seed checkpoint by dev value MSE only, earliest tie, epoch0 included. Final quantities/weights/epochs and expected runtime will be locked in FINAL_PLAN.json and committed/pushed after pilot, before main generation. Changes permitted only from pilot technical/cost evidence, not main outcomes. Total target<=6h including implementation; no unbounded search or optional sample extension.

## Independent evaluation
New common64prefix bank,2seats×3seeds=384 games per comparison. Five fixed comparisons A/gen4, B/gen4, C/gen4, C/A, C/B (1920 games). CPU500ms,width4,max6. No heavy generation/training/audit overlaps timed evaluation. Cluster by prefix across seeds and seats;20k bootstrap,95% descriptive and Bonferroni99% intervals for5 primary comparisons. Adoption of C requires corrected lower bounds>50% against gen4,A,B and positive mean score differences, plus correctness audits. B/A can be assessed descriptively using paired common-prefix results againstgen4, not an extra confirmatory test. C/A,C/B directly isolate architecture/auxiliary input contributions imperfectly because gradients differ; report this limitation.
Old evaluation games are not pooled. No independent-result checkpoint choice, lucky seed filtering, or extension until significance. Report timing/depth/fallback and parameter/effective inference differences. Uncertain/negative results are valid; no general ceiling claim.
