# 固定線形L：新256prefixによる独立標本確認

## 計画と位置付け
これは旧T実験のgate未達を変更せず、線形Lで得た探索的示唆を別途事前計画で確認する試験。追加訓練・モデル/seed選別なし。旧32prefixを合算しない。独立標本への確認であり、秘書による独立実装監査とは呼ばない。

Lはb32b89cの終点24係数価値と旧30係数方策。元の学習済み24係数を初期値に、凍結広幅B自己対戦から実終局WDLを1,024ゲーム/seed・8epochで学び直した値で、gen3の着手/値は教師に使っていない。Fは元混成線形価値。両者の方策係数は同一で、24×8/2ply/100ms完成段階探索も同じ。gen3は対応固定1751401/2/3の公開PPO単体。

新256prefix×先後交換×3seed、L/FとL/gen3各1,536局を固定。過去非NN評価の全訪問431,990状態も除外し、全訓練訪問indexと旧評価開始状態から分離したbankを先にhash固定した。初期空盤面などprefix生成前の共通状態は採用評価開始状態と区別し、評価本体は4ply後から。

point=(勝ち+引分×0.5)/対局数。prefixごと6局cluster bootstrap20,000回、通常95%CIと2主比較Bonferroni family2 CI（各97.5%）を併記。補正下限50%超のみ各対照への優越判定。得点差CIは通常95%。seed別・先後別は補助解析で、全seed一般化や同等性証明にしない。
