# 終局価値探索：今回の結論

目標の安定した優越は未達成。ただし4段階目に有望な改善を観測しました。最初の失敗で停止せず、(1)終局回帰、(2)別継続の探索葉追加と終盤制限、(3)小型CNN・追加6000局・対称変換・root一括推論、(4)時間超過を受けた逐次探索への復帰を実施しました。

最終fresh holdout seed95000は24prefix、各組先後交換48局。3seed平均の得点差は非学習探索に+2.146、seed×prefix bootstrap95%区間[+0.291,+3.875]。既存Cの候補順位を同じ時間制御探索器に組み込んだ対照には+1.194、区間[-0.500,+2.903]。各seedの点推定はどちらの相手にも正ですが、全seedの区間が正ではありません。3seed・24prefix・反復的設計変更・多重比較未補正のため暫定結果です。元の固定幅C-searchをそのまま比較したものではなく、共通時間制御版C対照です。

全方式に6ms/手を配分し、最終比較の学習モデル実時間は4.575〜4.690ms/手、対照は4.327〜4.570ms/手（valueとの組）。実時間を完全一致させた比較ではありません。value超過率0〜0.80%、対照0.27〜1.75%。遅延した子の結果は破棄。第3段階batched版は一部約20%の超過で比較品質に問題があり、推奨から除外しました。詳細ノード数/各区間時間/全decision時間は結果JSONにあります。

学習は9モデル・24000更新、GPU学習ループ累計30.672秒（初期smoke/再開検証を除く）。30分上限を大きく下回っています。実験は最終結果回帰なので、長く回すだけで棋力向上を期待できるとは判断しません。データは8700本のbase対局＋3600本の独立した枝の終局継続。第1/2段階全体287.63秒、第3段階111.03秒＋先に生成した6000局74.57秒、第4段階の時間はrun-summary.jsonのmatch_wall_secondsを参照（学習0秒）。学習と生成・評価の時間は分けています。

flatの過学習は未使用対局MSE悪化で確認。小型モデルの予測MSEは静的0.04552から0.03389〜0.03512へ改善しました。しかし継続方策の平均得点誤差と候補間の順位精度は別であり、探索分布への一般化は未解決です。対称化による手番の先行利益の抑制も検討対象です。

次の候補は、同一局面の複数候補を共通の継続乱数で終局まで評価する差分/ランキング学習、手番利益を残した価値構造のablation、および独立prefix拡大です。追加予算の判断用にここで有限runを終了し、checkpointと全結果を保持します。最終holdoutを使ったモデル再選択はしません。試用例にはvalidation最高criterionのseed201（alpha0.5、gate24、incremental）を使います。
