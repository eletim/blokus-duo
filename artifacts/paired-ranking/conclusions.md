# 今回の結論

同一局面候補の差分/ランキング学習は実装・3seed実学習・比較を完了しました。**非学習探索への優位は確認できましたが、現valueモデルからの追加改善は示せませんでした。** 既存value(seed201,alpha0.5,gate24)を推奨のまま保持します。差分モデルの試用例seed301はvalidation最高criterionによるもので、holdoutによる再選択はしていません。

## 新規96prefixの最終結果

最終評価は時間推定の不具合修正後、fresh seed230000、96prefix/組、先後交換192局/組。共通6ms予算です。3seed平均得点差とseed×prefix bootstrap95%区間:

- 非学習探索: +2.583 [ +1.773, +3.325 ]。各seedのprefix区間もすべて正でした。
- 現value: -0.066 [ -0.688, +0.578 ]。各seedの区間はすべて0を含みます。
- 対照の現value単体も非学習探索に+2.443 [ +1.641, +3.219 ]。

実時間は差分モデル4.572〜4.685ms/手、非学習探索4.367〜4.393ms/手、直接対戦の現value4.600〜4.642ms/手。差分モデルの6ms超過率0.10〜0.30%。実時間を完全一致させた比較ではなく、合法手生成/順位付け/GPU同期込みの同一時間予算を与えています。探索nodes、各工程時間、全decision時間もJSONに記録。3seedは同一初期checkpointと同一生成データを共有する更新乱数の3seedで、独立した事前学習全体を3回再現したものではありません。96prefixへの拡大でも、多重比較未補正・相手pool限定の限界は残ります。

## 時間制御の修正

旧探索器では一度の大遅延で費用推定が予算を超えると、その後の子探索を拒否し続け推定値も更新しなくなる問題がありました。初回holdoutのseed303/priorの平均1.623ms/手から検出。初回結果と実行時sourceを保全し、費用観測と推定値を予算に対して上限化しました。100ms擬似遅延の次手で探索が回復するテストを追加。すべての対照へ同じ修正を適用し、全重み・混合率を固定したままfresh holdoutへ移行しました。初回holdoutは学習優劣の結論に使用しません。

## 原因分析と次案

未使用240groupの候補差分MSEは元モデル0.010294から0.009956〜0.010102へ小幅に改善しましたが、順位正解率は元72.88%に対し71.44〜72.66%で改善しませんでした。終局2継続間の候補差分の不一致MSEは0.01109（方策差も含み、純粋な乱数分散ではない）。これらは追加学習の信号が弱いことを示しますが、原因の因果証明ではありません。

学習データはheuristic最良応手1つの先の葉を使う一方、実探索は相手上位3応手の最小値を選びます。また継続方策は非学習/A2で、現valueとの対戦分布と異なります。候補差分回帰の誤差を減らしても重要な順位逆転が減らない可能性があります。モデルの反対称制約の限界も残ります。

次案は、実探索と同じ3応手を含むgroup生成、現valueを含む継続相手pool、候補順位が曖昧な局面への追加完走配分です。順位損失/差分損失/単純な絶対値追加学習のablationを新validationで比較し、予測MSEではなく局面ごとの意思決定損失も検証する価値があります。今回のholdoutでcheckpointを選び直すことはしません。追加予算・優先順位は秘書の次段階判断へ引き継ぎます。
